# Tunnel (T) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire `gw-tunnel-client` into `gw-proxy::filters::upstream::pick_peer` so `--features tunnel` graduates from "dead code re-export" to "decides Direct vs Tunnel per request" with config / persistence / telemetry support, matching [`docs/superpowers/specs/2026-05-22-tunnel-t-design.md`](../specs/2026-05-22-tunnel-t-design.md).

**Architecture:** A new `TunnelStack` lives in `gw-proxy::tunnel_stack`. It holds an ArcSwap of `ProxyNodeView`s sourced from a new `proxy_nodes` table via `EntityStore::proxy_nodes_or_load`, a `DashMap<node_id, Arc<ReconnectingTransport>>`, and an `Arc<SafeDnsResolver>`. `LlmGateway::new` gains an `Option<Arc<TunnelStack>>` field; `pick_peer` calls `TunnelStack::resolve` after the strategy pick and either keeps the existing Direct `HttpPeer` or replaces it with `TunnelStack::peer_for_node`. Bootstrap constructs the stack only when `cfg.tunnel.enabled = true`. `VendorKey` carries a new optional `tunnel_preference`. New error codes (`GW_TUNNEL_NO_NODE`, `GW_TUNNEL_NO_LIVE`, `GW_TUNNEL_TARGET_DENIED`, `GW_TUNNEL_DNS_BLOCKED`) participate in R-E failover via `ctx.retry_blacklist`. `hickory-resolver` is bumped to 0.25 so the rustls 0.21/0.23 double-link disappears.

**Tech Stack:** Rust 1.86 / Pingora 0.8 / tokio / `gw-tunnel-client` (frame + transport + pool + resolver + safe_dns + target_filter) / hickory-resolver 0.25 / sqlx 0.8 / fred 9 / arc-swap / dashmap / moka / figment.

   - `cargo build -p <crate>` clean for every touched crate

In the same file, near `SignatureAlgo`:

```rust
/// Wire-shape mirror of `gw_store::encrypt::EncryptedKey`. `gw-core` cannot
/// depend on `gw-store`, so the decryption call lives in the loader (see
/// `crates/gw-store/src/loader.rs::load_proxy_node`). Field names match
/// `gw_store::encrypt::EncryptedKey` so the JSONB payload round-trips.
pub mod entity_helpers {
    use serde::{Deserialize, Serialize};
    #[derive(Clone, Debug, Serialize, Deserialize)]
    pub struct EncryptedBlob {
        pub kek_kid: String,
        #[serde(with = "base64_bytes")]
        pub nonce: Vec<u8>,
        #[serde(with = "base64_bytes")]
        pub ciphertext: Vec<u8>,
    }
    mod base64_bytes {
        use serde::{Deserialize, Deserializer, Serializer};
        pub fn serialize<S: Serializer>(b: &[u8], s: S) -> Result<S::Ok, S::Error> {
            s.serialize_str(&base64_encode(b))
        }
        pub fn deserialize<'de, D: Deserializer<'de>>(d: D) -> Result<Vec<u8>, D::Error> {
            let s = String::deserialize(d)?;
            base64_decode(&s).map_err(serde::de::Error::custom)
        }
        fn base64_encode(b: &[u8]) -> String {
            const A: &[u8;64] = b"ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/";
            let mut out = String::with_capacity((b.len()+2)/3*4);
            for chunk in b.chunks(3) {
                let n = u32::from_be_bytes([0, *chunk.first().unwrap_or(&0), *chunk.get(1).unwrap_or(&0), *chunk.get(2).unwrap_or(&0)]);
                for i in 0..4 {
                    if i <= chunk.len() {
                        out.push(A[((n >> (18 - 6*i)) & 0x3f) as usize] as char);
                    } else { out.push('='); }
                }
            }
            out
        }
        fn base64_decode(s: &str) -> Result<Vec<u8>, &'static str> {
            let s = s.trim_end_matches('=');
            let mut out = Vec::with_capacity(s.len()*3/4);
            let mut buf = 0u32; let mut bits = 0u32;
            for c in s.bytes() {
                let v: u32 = match c {
                    b'A'..=b'Z' => (c - b'A') as u32,
                    b'a'..=b'z' => (c - b'a' + 26) as u32,
                    b'0'..=b'9' => (c - b'0' + 52) as u32,
                    b'+' => 62,
                    b'/' => 63,
                    _ => return Err("bad b64 char"),
                };
                buf = (buf << 6) | v;
                bits += 6;
                if bits >= 8 {
                    bits -= 8;
                    out.push(((buf >> bits) & 0xff) as u8);
                }
            }
            Ok(out)
        }
    }
}
```

(The base64 helpers above stay tiny and inline — there is no base64 dep in `gw-core` and adding one for one struct is overkill. If a workspace-wide base64 crate is added later, this can be swapped in a follow-up.)

```rust
/// Whole-table scan for the live `proxy_nodes` list. Used by
/// `TunnelStack::reload_nodes` (ADR-T-3). The list is small in practice
/// (≤ low hundreds) so a single PG round-trip is fine; the ArcSwap inside
/// TunnelStack is what makes hot-path reads lock-free.
pub async fn load_proxy_nodes_list(
    ctx: &LoaderCtx,
) -> anyhow::Result<Vec<gw_core::entity::ProxyNode>> {
    use sqlx::Row;
    let rows = sqlx::query(PROXY_NODE_LIST_SQL).fetch_all(&ctx.pg).await?;
    let mut out = Vec::with_capacity(rows.len());
    for row in rows {
        let payload: serde_json::Value = row.try_get("payload")?;
        let node: gw_core::entity::ProxyNode = serde_json::from_value(payload)?;
        out.push(node);
    }
    Ok(out)
}
```

```rust
pub async fn proxy_node_or_load(&self, id: &str) -> Option<Arc<Versioned<ProxyNode>>> {
    if let Some(hit) = self.proxy_node.get(id).await {
        return Some(hit);
    }
    let loader = self.loader.as_ref()?.clone();
    let id2 = id.to_owned();
    let deadline = self.cold_load_timeout;
    self.proxy_node
        .try_get_with_by_ref(id, async move {
            with_cold_load_timeout("proxy_node", deadline, async move {
                load_proxy_node(&loader, &id2).await
            })
            .await
            .map(Arc::new)
            .ok_or_else(|| anyhow::anyhow!(COLD_LOAD_MISS_SENTINEL))
        })
        .await
        .ok()
}
```

```rust
pub fn resolve_tunnel(ctx: &TunnelResolveCtx<'_>, nodes: &[ProxyNodeView]) -> TunnelResolution {
    let mut filtered: Vec<&ProxyNodeView> = nodes
        .iter()
        .filter(|n| n.enabled)
        .filter(|n| n.allowed_provider_ids.iter().any(|p| p == ctx.provider_id))
        .filter(|n| {
            n.allowed_vendor_key_ids.is_empty()
                || n.allowed_vendor_key_ids.iter().any(|k| k == ctx.vendor_key_id)
        })
        .collect();

    if !ctx.preference.preferred_node_ids.is_empty() {
        let allow: std::collections::HashSet<&str> =
            ctx.preference.preferred_node_ids.iter().map(String::as_str).collect();
        filtered.retain(|n| allow.contains(n.id.as_str()));
    }

    if filtered.is_empty() {
        // Caller maps require_tunnel=true to GW_TUNNEL_NO_NODE; Direct stays
        // the resolver's representation of "no preference satisfied".
        return TunnelResolution::Direct;
    }

    if ctx.preference.prefer_low_latency {
        filtered.sort_by_key(|n| n.latency_ms);
    }
    TunnelResolution::Use(filtered[0].id.clone())
}
```

```rust
//! Tunnel decision stack — pluggable into `LlmGateway`.
//!
//! Owns the per-node `Arc<ReconnectingTransport>` pool, the live
//! `Vec<ProxyNodeView>` snapshot (ArcSwap), and the `SafeDnsResolver`.
//! `pick_peer` calls `resolve` and, when the result is `Use(node_id)`,
//! `peer_for_node` materialises an `HttpPeer` whose socket terminates at
//! the proxy node's WS endpoint (the real upstream is encoded in the
//! tunnel frame payload).
//!
//! ADR-T-2, ADR-T-3, ADR-T-4 in
//! `docs/superpowers/specs/2026-05-22-tunnel-t-design.md`.

#![cfg(feature = "tunnel")]

use arc_swap::ArcSwap;
use dashmap::DashMap;
use gw_core::entity::TunnelPreference;
use gw_tunnel_client::pool::{PoolConfig, ReconnectingTransport};
use gw_tunnel_client::resolver::{
    resolve_tunnel, ProxyNodeView, TunnelResolution, TunnelResolveCtx,
};
use gw_tunnel_client::safe_dns::SafeDnsResolver;
use gw_tunnel_client::transport::TransportConfig;

use std::sync::Arc;

/// Error returned by `peer_for_node` when the chosen transport is not yet
/// connected. Mapped to `GW_TUNNEL_NO_LIVE` in `filters::upstream`.
#[derive(Debug)]
pub enum TunnelPeerError {
    /// `ReconnectingTransport::current()` returned `None`.
    NoLive { node_id: String },
    /// `target_filter::assert_target_allowed` rejected the host:port.
    TargetDenied { host: String, port: u16 },
}

pub struct TunnelStack {
    /// node_id -> reconnecting transport. Created lazily on first use.
    transports: DashMap<String, Arc<ReconnectingTransport>>,
    /// Live `ProxyNodeView`s. Swapped wholesale by `reload_nodes`.
    nodes: ArcSwap<Vec<ProxyNodeView>>,
    /// DoH resolver shared with `peer_for_node` for SSRF-safe lookups.
    /// `None` if `cfg.tunnel.doh` is unset (cloudflare default is built in T5).
    #[allow(dead_code)] // wired in T5 health-probe; placeholder field for v1.
    dns: Arc<SafeDnsResolver>,
    /// Pool config applied to every newly-spawned `ReconnectingTransport`.
    pool_cfg: PoolConfig,
    /// Transport config template (only `url` differs per node).
    transport_cfg_template: TransportConfig,
}

impl TunnelStack {
    pub fn new(
        nodes: Vec<ProxyNodeView>,
        dns: Arc<SafeDnsResolver>,
        pool_cfg: PoolConfig,
        transport_cfg_template: TransportConfig,
    ) -> Self {
        Self {
            transports: DashMap::new(),
            nodes: ArcSwap::from_pointee(nodes),
            dns,
            pool_cfg,
            transport_cfg_template,
        }
    }

    /// Wholesale-swap the live node list. Called by the bootstrap-side
    /// invalidation subscriber (T5) when the stream consumer sees a
    /// `proxy_node` namespace event.
    pub fn reload_nodes(&self, nodes: Vec<ProxyNodeView>) {
        self.nodes.store(Arc::new(nodes));
    }

    /// Decide Direct vs Tunnel for a given (provider, key, preference).
    pub fn resolve(
        &self,
        provider_id: &str,
        key_id: &str,
        pref: &TunnelPreference,
    ) -> TunnelResolution {
        let nodes = self.nodes.load_full();
        let ctx = TunnelResolveCtx {
            provider_id,
            vendor_key_id: key_id,
            preference: pref,
        };
        resolve_tunnel(&ctx, &nodes)
    }

    /// Build an `HttpPeer` whose socket terminates at the given node's
    /// WS endpoint. The real upstream (`host:port`) is encoded as a
    /// `MsgType::Open` frame payload over the tunnel — Pingora itself
    /// only sees the gateway-to-node TLS connection.
    pub async fn peer_for_node(
        &self,
        node_id: &str,
        host: &str,
        port: u16,
    ) -> Result<HttpPeer, TunnelPeerError> {
        // Lazily create the transport on first use.
        let transport = if let Some(t) = self.transports.get(node_id) {
            t.clone()
        } else {
            // The node ws_url comes from the matching ProxyNodeView; in v1 we
            // re-read it from the snapshot. If the node disappeared between
            // resolve() and here, fall through to NoLive.
            let url = match self
                .nodes
                .load()
                .iter()
                .find(|n| n.id == node_id)
                .map(|n| n.ws_url.clone())
            {
                Some(u) => u,
                None => {
                    return Err(TunnelPeerError::NoLive {
                        node_id: node_id.to_owned(),
                    });
                }
            };
            let mut cfg = self.transport_cfg_template.clone();
            cfg.url = url;
            let t = ReconnectingTransport::start(cfg, self.pool_cfg.clone()).await;
            self.transports.insert(node_id.to_owned(), t.clone());
            t
        };

        if transport.current().is_none() {
            metrics::counter!(
                "gw_tunnel_open_total",
                "node_id" => node_id.to_owned(),
                "result" => "no_live",
            )
            .increment(1);
            return Err(TunnelPeerError::NoLive {
                node_id: node_id.to_owned(),
            });
        }

        let target = format!("{host}:{port}");
        let target_url: url::Url = format!("https://{target}").parse().map_err(|_| {
            TunnelPeerError::TargetDenied {
                host: host.to_owned(),
                port,
            }
        })?;
        if gw_tunnel_client::target_filter::assert_target_allowed(&target_url).is_err() {
            metrics::counter!(
                "gw_tunnel_open_total",
                "node_id" => node_id.to_owned(),
                "result" => "target_denied",
            )
            .increment(1);
            return Err(TunnelPeerError::TargetDenied {
                host: host.to_owned(),
                port,
            });
        }

        // Build the HttpPeer whose socket terminates at the WS node.
        // Pingora dials this address as a TLS endpoint; the frame layer
        // upgrades it to a WebSocket once connected (the transport already
        // owns that ws handshake).
        let view_url = self
            .nodes
            .load()
            .iter()
            .find(|n| n.id == node_id)
            .map(|n| n.ws_url.clone())
            .ok_or_else(|| TunnelPeerError::NoLive {
                node_id: node_id.to_owned(),
            })?;
        let node_host = view_url.host_str().unwrap_or("").to_string();
        let node_port = view_url.port_or_known_default().unwrap_or(443);
        let tls = view_url.scheme().eq_ignore_ascii_case("wss");
        Ok(HttpPeer::new(
            format!("{node_host}:{node_port}"),
            tls,
            node_host,
        ))
    }
}
```

```rust
//! aether-hub mock: WS listener that decodes `MsgType::Open { target }` and
//! forwards subsequent `Data` frames to a TCP connection against `target`.
//! Used by `crates/gw-gateway/tests/e2e_tunnel.rs` to exercise the
//! gateway → node → real-upstream loop end-to-end without spinning up the
//! real aether-hub.

use bytes::{Bytes, BytesMut};
use futures_util::{SinkExt, StreamExt};
use std::collections::HashMap;
use std::sync::Arc;
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use tokio::net::{TcpListener, TcpStream};
use tokio::sync::Mutex;
use tokio_tungstenite::{accept_async, tungstenite::Message};

const MAGIC: [u8; 2] = [0xAE, 0x21];

#[derive(Copy, Clone)]
enum Mt { Open = 0x01, Data = 0x02, Close = 0x03, Ping = 0x04, Pong = 0x05 }

fn encode(mt: Mt, stream_id: u32, payload: &[u8]) -> Vec<u8> {
    let mut buf = Vec::with_capacity(14 + payload.len());
    buf.extend_from_slice(&MAGIC);
    buf.push(1); // version
    buf.push(mt as u8);
    buf.extend_from_slice(&0u16.to_be_bytes()); // flags
    buf.extend_from_slice(&stream_id.to_be_bytes());
    buf.extend_from_slice(&(payload.len() as u32).to_be_bytes());
    buf.extend_from_slice(payload);
    buf
}

fn decode_header(buf: &[u8]) -> Option<(u8, u32, usize)> {
    if buf.len() < 14 { return None; }
    if buf[0..2] != MAGIC { return None; }
    if buf[2] != 1 { return None; }
    let mt = buf[3];
    let stream_id = u32::from_be_bytes([buf[6], buf[7], buf[8], buf[9]]);
    let length = u32::from_be_bytes([buf[10], buf[11], buf[12], buf[13]]) as usize;
    Some((mt, stream_id, length))
}

/// Start a tunnel-mode WS listener on `addr`. Blocks forever; spawn it.
pub async fn run(addr: std::net::SocketAddr) -> std::io::Result<()> {
    let listener = TcpListener::bind(addr).await?;
    eprintln!("fake-upstream tunnel listener on {addr}");
    loop {
        let (sock, _peer) = listener.accept().await?;
        tokio::spawn(handle_conn(sock));
    }
}

async fn handle_conn(stream: TcpStream) {
    let ws = match accept_async(stream).await {
        Ok(w) => w,
        Err(e) => { eprintln!("ws handshake fail: {e}"); return; }
    };
    let (mut sink, mut src) = ws.split();
    let sink = Arc::new(Mutex::new(sink));
    let streams: Arc<Mutex<HashMap<u32, tokio::sync::mpsc::Sender<Bytes>>>> =
        Arc::new(Mutex::new(HashMap::new()));

    while let Some(msg) = src.next().await {
        let bin = match msg {
            Ok(Message::Binary(b)) => b,
            Ok(Message::Close(_)) | Err(_) => break,
            _ => continue,
        };
        let (mt, stream_id, length) = match decode_header(&bin) {
            Some(t) => t, None => continue,
        };
        let payload = &bin[14..14+length.min(bin.len()-14)];
        match mt {
            x if x == Mt::Ping as u8 => {
                let pong = encode(Mt::Pong, stream_id, payload);
                let _ = sink.lock().await.send(Message::Binary(pong)).await;
            }
            x if x == Mt::Open as u8 => {
                let target = String::from_utf8_lossy(payload).to_string();
                let (tx, rx) = tokio::sync::mpsc::channel::<Bytes>(16);
                streams.lock().await.insert(stream_id, tx);
                let sink_c = sink.clone();
                let streams_c = streams.clone();
                tokio::spawn(forward(stream_id, target, rx, sink_c, streams_c));
            }
            x if x == Mt::Data as u8 => {
                if let Some(tx) = streams.lock().await.get(&stream_id) {
                    let _ = tx.send(Bytes::copy_from_slice(payload)).await;
                }
            }
            x if x == Mt::Close as u8 => {
                streams.lock().await.remove(&stream_id);
            }
            _ => {}
        }
    }
}

async fn forward(
    stream_id: u32,
    target: String,
    mut rx: tokio::sync::mpsc::Receiver<Bytes>,
    sink: Arc<Mutex<futures_util::stream::SplitSink<tokio_tungstenite::WebSocketStream<TcpStream>, Message>>>,
    streams: Arc<Mutex<HashMap<u32, tokio::sync::mpsc::Sender<Bytes>>>>,
) {
    let mut tcp = match TcpStream::connect(&target).await {
        Ok(s) => s,
        Err(e) => {
            eprintln!("tunnel forward connect {target} failed: {e}");
            return;
        }
    };
    let (mut r, mut w) = tcp.split();

    let sink_w = sink.clone();
    let read_task = tokio::spawn(async move {
        let mut buf = [0u8; 16384];
        loop {
            let n = match r.read(&mut buf).await {
                Ok(0) => break,
                Ok(n) => n,
                Err(_) => break,
            };
            let frame = encode(Mt::Data, stream_id, &buf[..n]);
            if sink_w.lock().await.send(Message::Binary(frame)).await.is_err() {
                break;
            }
        }
    });
    while let Some(bytes) = rx.recv().await {
        if w.write_all(&bytes).await.is_err() { break; }
    }
    drop(read_task);
    streams.lock().await.remove(&stream_id);
}
```
