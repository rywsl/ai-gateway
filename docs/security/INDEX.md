# Security Artifacts Index

- `disclosure-process.md` - embargo and release-gate process.
- `advisories/<advisory-id>.md` - advisory drafts and release records.
- `internal-audit/<audit-id>.csv` - affected-customer audit outputs.
- `internal-audit/queries.sql` - repeatable audit query templates.
- `cve-decision-tree.md` - CVE filing decision tree.
- `external-reporter-sop.md` - coordinated disclosure SOP.
- `changelog-template.md` - security release note template.
- `warn-only-protocol.md` - 14-day warn-only protocol.
- `ws-16-launch-gate.md` - launch checklist.
- `templates/reporter-*.md` - reporter communication templates.

Customer names, email addresses, tokens, raw JWTs, API keys, and payload samples do not belong in this directory.
