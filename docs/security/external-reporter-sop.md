# External Reporter SOP

## Intake

- Accept reports only through `security@ailinkmax.com` or the repository Security advisory flow.
- If a report arrives through a public issue, support ticket, or chat, move the conversation to the security channel and remove exploit details from public surfaces where possible.
- Acknowledge receipt within 24h.

## Assessment

- Initial severity and affected component assessment within 72h.
- Fix ETA or reasoned update within 7 days.
- Agree embargo with the reporter in writing. Default upper bound is 90 days or fix released, whichever comes first.

## Credit

Reporter credit is opt-in. Confirm the exact public name, handle, and organization before adding it to advisory `Credit`.

## Templates

Use:

- `templates/reporter-ack.md`
- `templates/reporter-embargo.md`
- `templates/reporter-disclosure.md`
