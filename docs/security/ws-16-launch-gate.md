# WS-16 Launch Gate

## Checklist

- [ ] Advisory R1 status is `released` or an approved written extension exists.
- [ ] Advisory R2 status is `released` or an approved written extension exists.
- [ ] Advisory R3 status is `released` or an approved written extension exists.
- [ ] Advisory R4 status is `released` or an approved written extension exists.
- [ ] Internal-audit CSV files exist for R1-R4 and have review files.
- [ ] CVE decision is recorded in each advisory frontmatter.
- [ ] Warn-only metric protocol is active or completed.
- [ ] CHANGELOG security entries exist for R1-R4.
- [ ] `SECURITY.md` is present and mirrored in both repositories.
- [ ] Process docs exist: disclosure process, CVE decision tree, external reporter SOP, warn-only protocol.

Launch cannot rely on `draft` advisories. An `embargoed` advisory requires a team-lead and security-owner written extension.
