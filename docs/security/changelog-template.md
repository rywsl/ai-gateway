# Security Changelog Template

Use one entry per advisory.

```markdown
### Security

- AILMX-2026-XXX: <short customer-safe title>.
  - Severity: P0|P1
  - Affected configurations: <specific configuration set>
  - Fix: <version> / <git sha>
  - Upgrade guidance: <action>
  - Advisory: docs/security/advisories/<id>.md
```

Do not include proof-of-concept details, raw customer identifiers, tokens, or exploit primitives.
