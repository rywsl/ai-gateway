# Security policy

## Reporting a vulnerability

- Email: security@ailinkmax.com
- GitHub Security Advisories: use the repository Security advisory flow if available.
- PGP key: to be published before public intake opens.

Do not open public issues for suspected vulnerabilities. Include the affected component, version, configuration, and a minimal reproduction that avoids customer data.

## What happens next

- T+24h: acknowledgement.
- T+72h: initial assessment.
- T+7d: fix ETA or a reasoned update.
- Embargo: agreed with the reporter, default 90 days or fix released, whichever comes first.

Reporter credit is opt-in and is confirmed before publication.
